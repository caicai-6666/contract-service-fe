# 前端登录与鉴权

> 本平台使用知识沉淀统一入口提供的用户凭据。后端负责验证用户登录及当前平台访问资格，前端不再收集密钥或签发免登码。

## 统一入口与凭据

统一入口负责保存及更新同源 `localStorage` 中的 `access_token`，值为原始 token 字符串，不带 `Bearer ` 前缀，不使用 JSON 包装。入口与合同平台必须使用相同协议、域名和端口，不同路径共享存储；直接访问不同的本地 Vite 端口不构成同源。

本项目每次请求读取最新 token，不写入或清除共享键，不从 URL、旧 `sessionStorage` 或旧登录接口获取备用凭据。缺少、格式非法或无法读取 token 时，不发起业务请求，显示“请从知识沉淀入口进入”。

## 身份确认与页面状态

进入页面后先请求 `GET /knowledge-accumulation/contract/api/auth/me`，使用 `Authorization: Bearer <access_token>` 且不缓存。成功响应必须含非空字符串 `userid`、`username` 以及正整数 `ttl`；身份按后端原值保存在本页内存中。确认成功后才挂载合同库、处理流和关系网，顶部显示 `username`。刷新页面重新验证，不凭旧缓存直接进入工作台。

身份确认期间采用与注册中心一致的五色竖条动画；错误提示采用磨砂卡片和浅灰浮雕返回按钮。根页面按以下规则处理失败：

| 情况 | 页面行为 |
| --- | --- |
| 缺少或无法读取凭据 | 提示从统一入口进入 |
| 401 | 显示“登录状态已失效” |
| 403 | 显示“暂无合同平台访问权限” |
| 网络失败、15 秒身份确认超时、503 或无效响应 | 显示可重试错误，不判断为登录失效 |

所有回退页提供“返回知识沉淀”普通链接：开发为 `/dev/knowledge-accumulation/`，生产为 `/knowledge-accumulation/`。工作台原退出按钮也改为此链接，不执行统一入口登出或删除共享 token。当前目标路由保留。

监听共享键的跨标签页变更，并在窗口重新聚焦时检查 token：发生变化后销毁旧工作台、关闭审核信箱并重新确认身份。旧 token 请求的迟到 401/403 不覆盖新凭据对应的状态。用户资料始终与成功验证时使用的 token 绑定，不能给新 token 复用旧身份。

## 请求与连接边界

全部合同 API、PDF 和 SSE 新连接通过 `contractApiFetch` 读取最新共享 token，并附加 Bearer 请求头。该入口仅接受本平台同源 API 路径并禁止重定向，不向外部网页发送凭据；正文中的网页链接探测仍不带合同凭据。

生产 API 前缀为 `/knowledge-accumulation/contract/api`，开发为 `/dev/knowledge-accumulation/contract/api`。开发时 Vite 去除 `/dev` 后转发至后端，同时接受网关已经去除 `/dev` 的 API 请求；Docker Nginx 保留完整生产路径转发，不进入 SPA 回退。页面及静态资源路径见[页面路由](routing.md)，容器配置见[Docker 部署](docker.md)。

业务请求返回 401/403 时释放本页身份与工作台缓存，显示对应回退页，但不修改共享 token；503 等服务异常保留原有业务错误及重试入口。SSE 不设置身份查询的 15 秒期限，原有自动重连策略继续生效。

`ttl` 表示后端本次身份查询续期的秒数，不是前端缓存期限。本项目不根据 TTL 伪造身份有效性，也不通过后台计时器无限续期；后续请求及 SSE 新连接由后端重新验证。已建立 SSE 的心跳不等于登录续期。

## 会话缓存

智能助手的标签页恢复缓存按稳定 `userid` 的 SHA-256 分区，不按 token 或显示名称分区。同一用户 token 更新后可恢复原有会话，不同用户互不读取。旧免登码分区不迁移，后端会话历史仍通过接口读取；缓存仅用于页面恢复，不承担授权。

## 验证范围

- 验证共享 token 的读取、轮换、缺失和存储不可用，不写入或清除共享凭据。
- 验证 `/auth/me` 成功后才挂载业务模块，401/403/503、非法响应、取消及超时正确分流。
- 验证业务、PDF、SSE 携带最新 token，旧请求迟到失败不影响新身份。
- 验证开发和生产页面、静态资源及 API 前缀、深层路由刷新和 Nginx 转发。
