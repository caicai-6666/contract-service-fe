# 合同文件柜三维场景

> 本文说明合同库右侧 Three.js 文件柜原型的交互边界，不定义真实合同文件、目录或后端存储结构。

## 场景结构

文件柜以正对用户的窄视角透视展示，固定包含五层抽屉。相机保留轻微俯角，但通过较远机位压低柜体竖线的透视收拢，避免产生柜体侧向旋转的错觉。初始位置具有明确且不可越过的左侧尽头，并在场景左侧保留起始留白；向右浏览时柜体会进入并填满该留白，柜体列离开实际视野后再循环复用，形成没有明显右侧终点的视觉效果。返回最左端时，起始留白重新完整出现。

起始留白不是空白背景，而是图书馆入口处的固定档案索引墙。索引墙包含石质外框、发光目录面板、分层指示、馆藏展示龛和黄铜收边，与文件柜左端共享固定的世界位置；相机向右浏览后，索引墙会自然留在身后。

每个抽屉由暗色柜体腔体、抽屉托盘、圆角正面面板、内凹饰面、实体把手和标签位组成。面板包含边框层与固定件，托盘包含侧壁、上沿、内衬与后挡板。左右两侧采用三段式滑轨：外轨固定在柜体，中轨随开合移动约一半距离，内轨随抽屉完整伸出，并使用金属高光与滚珠表现机械层次。打开抽屉后，内部展示八份带标签的独立悬挂文件夹。文件夹使用带轻微弯曲和收边变化的双面薄纸封套，前袋、后页和侧面折角形成自然张口；内部合同页具有不同高度、宽度和倾角，并包含印刷线与局部印章。顶部采用暗色细悬挂骨架、黄铜端钩和无厚度纸质标签，避免产生厚板或货架横梁的观感。

文件柜位于现代档案图书馆中。环境以连续拱形结构划分空间，每个分区包含双层书架、实体书脊、石质立柱、黄铜嵌条、夹层步道、栏杆、悬吊灯和局部滑轨书梯。地面分为柜前抛光石材拼板与深绿色长条地毯，使用黄铜分缝、双层包边、重复徽章纹样和轨道嵌入式地灯建立细节与浏览方向。相机采用较远的窄视角机位，在保持柜体正向感的同时让上层馆藏空间进入画面。柜体框架、抽屉托盘和把手连接件产生接触阴影，抽屉内部使用克制的暖色补光区分前后空间。

前景沿地毯间隔摆放双层文件推车，推车包含金属框架、木质托盘、把手、轮组和不同状态的档案盒。部分推车带有可实际照亮档案与附近地面的暖色台灯。推车属于建筑分区中的世界对象，会随相机移动产生近景视差，并与所在分区一同在视野外循环。

场景以每个建筑分区的暖色吊灯为主要光源。吊灯使用向下聚光照亮柜体和地面，并通过较弱的暖色近场光保留相邻书架与拱顶细节；环境光与冷色方向光只负责暗部轮廓。各吊灯形成连续但彼此独立的亮区，分区间隙自然退入暗部；顶部灯槽、索引墙和轨道地灯仅提供低亮度引导，不承担整体照明。

横向浏览时相机沿图书馆移动，柜体左端与场景结构保持世界坐标不变；已经落到相机后方的重复柜列和建筑分区会循环到远端，以维持向右没有尽头的表现。环境只承担氛围与空间参照，不承载业务入口。

## 交互方式

场景不展示常驻的标题、状态或操作教学文字，画面空间完全交给文件柜和环境。抽屉检查退出按钮、抽屉与文件悬停信息仍按需出现，作为当前操作所必需的反馈。

- 在场景内左右拖动可横向浏览柜体，垂直拖动不改变场景位置。
- 鼠标滚轮或触控板滚动可横向移动柜体。
- 悬停抽屉时显示高亮和抽屉位置提示。
- 点击抽屉进入检查模式；场景始终最多只打开一个抽屉。
- 抽屉打开时向用户方向滑出，固定腔体、分段滑轨和托盘深度依次显露；相机同步移动到抽屉上方并聚焦内部整齐排列的文件。
- 检查模式下暂停横向浏览，并关闭其他抽屉的拾取、悬停与高亮反馈。再次点击当前抽屉、点击“关闭抽屉”或按 `Esc` 均可退出；抽屉关闭后相机返回进入检查前的浏览位置与视角。
- 抽屉完成打开后，悬停文件夹会触发轻微抬起和前移，仅点亮顶部悬挂骨架、端钩和小型选择标记，并显示文件名称与 PDF 预览提示。
- 页面最高层常驻一层默认完全透明且不拦截操作的玻璃膜。点击文件夹后，玻璃膜平滑增加暗色不透明度、背景模糊和饱和度收束，独立 PDF 查看框再浮到玻璃膜上方。
- PDF 查看框直接保留浏览器原生工具栏，不再增加自定义标题栏。退出按钮附着在查看框右上角；点击玻璃膜空白处、点击退出按钮或首次按下 `Esc` 均只退出预览并保留当前抽屉检查状态。

浏览位置不会小于左侧起点。相机经过柜体列后，该列从相机后方循环到远端，因此右侧可持续浏览。当前原型中的抽屉状态与物理复用列绑定，不代表未来真实合同文件的位置或持久化标识。八份原型文件当前统一使用 `src/assets/moe.pdf` 作为预览素材，文件名称和内容映射不代表真实业务数据。

## 技术边界

场景封装在独立 Vue 组件中，负责 Three.js 场景初始化、尺寸响应、指针拾取、动画循环及资源释放。组件卸载时应停止动画并释放几何体、材质与 WebGL 上下文。全屏 PDF 查看器封装为共享组件，由合同库文件和处理流查重候选共同复用，避免两处遮罩、动效和关闭交互发生漂移。

文件夹采用单套活动模型虚拟化：场景初始化时只创建八个文件夹并保持隐藏，不为每个物理抽屉复制模型。抽屉开始打开时，活动文件架挂载到当前抽屉并根据抽屉位置更新文件配色与数据；关闭过程中继续跟随抽屉，完全关闭后再隐藏并停放回柜体根节点。场景始终最多渲染一套文件夹，文件拾取和悬停动画也只遍历这八个活动模型。

关闭状态的抽屉只渲染正面板、把手和标签等可见结构；腔体、托盘和三段式滑轨在悬停或开合开始后才进入渲染。所有抽屉正面复用两套基础材质，悬停与选中反馈由单个高亮层跟随当前目标，避免为每个抽屉维护独立高亮材质。

重复结构采用分层批处理：书脊、滑轨滚珠和面板固定件使用 `InstancedMesh`；书架横板、栏杆、书梯和推车框架等同材质静态结构在创建时合并为较少的几何体。不会在运行时移动的节点冻结本地变换矩阵，柜列和建筑分区仅在浏览位置实际变化时更新世界位置。

场景按相机位置裁剪视野外的整列文件柜和建筑分区，当前打开抽屉所在柜列始终保留。各分区的局部灯光只在附近启用，只有距离相机最近的吊灯产生实时阴影；阴影贴图在横向浏览、抽屉开合、悬停或检查视角变化时按需刷新，静止画面不重复生成。以上优化不降低像素比上限、不关闭抗锯齿，也不删减可见场景细节。

柜列与建筑分区的循环复用以真实相机位置为基准，不使用仍可能领先于相机的滚动位置。对象只有在完整离开相机视锥并越过额外安全区后才会移动到远端；可见性裁剪距离随当前视口宽度计算，避免快速滚轮、快速拖动或容器尺寸变化时出现列提前消失。

PDF 预览打开时保留 Three.js 文件柜与分子背景各自最后一帧，但停止 Three.js 动画帧和分子背景 worker 的绘制。全屏玻璃膜因此只需模糊静态背景，不会因底层画布持续变化而在 PDF 滚动期间反复合成。退出预览后两套动画恢复；切换模块、退出登录或卸载场景时也会清除暂停状态，避免背景长期停留在冻结状态。

环境使用基础几何体、共享材质、静态灯光和少量低透明度粒子构成，不使用实时反射或外部高分辨率贴图。该取舍用于控制首屏资源、GPU 消耗和不同设备上的表现差异；后续若引入更复杂的环境资产，应重新评估加载与降级策略。

WebGL 无法初始化时，界面展示降级提示，不影响左侧智能助手继续使用。

场景画布填满合同库右侧分区，顶部与工作台标题栏下沿对齐，左侧直接衔接可拖动分割线，右侧和底部延伸到工作台内容边缘。右下角形状由工作台自身的圆角与溢出裁切统一控制，场景组件不再额外保留边距或圆角。

## 验证重点

- 任意可见抽屉均可进入和退出检查模式，同时打开的抽屉不超过一个。
- 检查模式的相机进入、抽屉开合与退出回位保持连续动画，内部文件在近距离下完整可见。
- 打开抽屉后，各文件夹可独立悬停和点击；未打开抽屉及其他抽屉中的文件不可交互。
- 关闭一个抽屉再打开其他抽屉时，活动文件架可正确复用，不出现文件残留、瞬移、材质串色或拾取失效。
- PDF 玻璃膜在关闭状态下完全透明且不阻挡页面操作，打开状态下覆盖整个页面并具有连续的磨砂与不透明度过渡。
- PDF 查看框资源与浏览器原生工具栏可加载，不出现额外标题栏；退出按钮、玻璃膜空白处和 `Esc` 均可关闭预览。退出后仍停留在原抽屉，继续退出才关闭抽屉并回到浏览视角。
- PDF 打开期间 Three.js 渲染帧保持不变，分子背景处于暂停状态；滚动 PDF 不触发底层画布更新，退出后两套动画均恢复。
- 抽屉开合、悬停和横向浏览保持连续动画。
- 浏览状态下不出现常驻标题、边界状态或拖动、滚轮、点击等教学文字；按需交互反馈仍可正常出现。
- 横向持续浏览时柜体列不会出现明显终点。
- 快速连续滚轮或拖动造成滚动位置明显领先于相机时，最左侧柜列在完整离开视锥前不会隐藏或循环，画面左侧不出现覆盖缺口。
- 柜列和建筑分区进入或离开裁剪范围时，不出现可见空洞、突然消失或灯光跳闪。
- 关闭抽屉时内部结构不参与渲染；悬停与开合开始后腔体、滑轨和托盘及时出现，不发生穿帮。
- 浏览静止后阴影停止重复刷新；继续横移、开合或悬停时阴影可以及时更新。
- 返回起点后可以看到固定左端，继续向左拖动不会越过边界。
- 容器尺寸变化后画布与相机比例正确更新。
- 页面离开或组件销毁后不残留动画循环和 WebGL 资源。
