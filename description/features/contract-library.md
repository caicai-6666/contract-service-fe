# 合同库档案筛选

> 本文说明工作台合同库右侧的正式合同目录、类别模型与本地筛选界面。类别与合同元数据均来自真实接口。

## 布局与使用

合同库保留左侧智能助手和双栏宽度调整。右侧由 `ContractArchivePanel.vue` 独立管理类型、时间筛选和合同列表，不影响助手会话。

双栏拖拽和键盘调整均为右侧保留至少 640px，保证签订时间标签、年月日滚轮与审核人筛选同处一行。容器不足以容纳左右两栏最小宽度时切换为上下布局；极窄屏的日期筛选行允许横向滚动，不挤压滚轮或换行。窗口和父容器尺寸变化后会重新约束拖拽宽度。

- 一级使用文件夹式按钮选择真实合同类别，以类别 ID 保存选择状态，不按名称关联；“全部合同”是前端独立入口，不混入服务端类别模型。类别接口没有数量，文件夹不展示合同数量。
- 选中的文件夹封面轻微打开，三张装饰纸页错落伸出；切换类型后原文件夹收回。纸页不代表合同数量、不响应点击，系统启用减少动态效果时直接切换状态。
- 二级使用独立年月日三栏滚轮，年月日标签位于滚轮外。从全部合同签订日期提取年份并去重升序排列，在最小年份前加入“—”并默认选中，表示不限年份。年、月、日都以“—”表示不限；选定年份但月份留空时显示全年合同，选定月份但日期留空时显示该月全部合同，年月日完整时筛选当天。切换类型保留时间条件。
- 列表按签署日期倒序、按年月分组，同日合同保持服务端顺序。每条合同左侧原样展示最终名称，下方展示类别和审核人；签署日期、入库日期固定在最右侧分两行对齐，不使用卡片内分割线。极窄栏将日期组移到下一行并保持右对齐。日期缺失显示“—”；签订日期不转换时区，入库时间转换为浏览器本地日期展示。
- 筛选结果总数显示在“合同档案”标题旁，不重复展示筛选条件摘要和各月份小计；无日期记录在列表末尾展示，不显示分组标题，也不提供独立筛选入口。
- 清空年份会清空并禁用月、日滚轮；清空月份会清空并禁用日滚轮。切换年月时将超出当月范围的日期修正到月末，包含闰年处理。不限年份时包含缺少签订日期的合同，指定年份后排除无日期合同。刷新后若选定年份已不存在，则恢复不限年月日。
- 滚轮停止后再确认筛选值，吸附与点击、键盘选择使用平滑对齐；三栏独立同步，避免互相打断。新的手势可中断程序对齐，减少动态效果模式下直接定位。
- 滚轮数字的缩放和透明度根据距离选中区中心的位置连续变化，不依赖筛选值提交后切换字号或字重；视觉反馈跟随滚动，筛选仍在停稳后确认。
- 没有匹配记录时显示空结果提示。每次改变筛选条件，列表回到顶部。
- 筛选切换时保留旧列表快照，仅当前列表可视区域内（含部分可见）的合同及日期分割线统一向上淡出，屏幕外内容不参与退场动画；完全退出后滚回顶部，再将最新结果按分割线与合同的实际顺序从下方交错淡入。快速切换只展示最新结果，空状态沿用进退场过渡；减少动态效果模式下直接更新。
- 签订时间右侧提供“全部 / 我审核入库”分段单选，默认全部，可与类别、日期条件组合；按合同 `reviewer` 与当前登录 `userName` 精确匹配。它只是共享目录的前端筛选，不是权限隔离。切换时更新结果数量并将列表滚回顶部。

桌面端筛选区域固定，结果列表独立滚动。类别采用单行横向滚动，避免全部类别占满结果空间，名称可换行；窄屏延续现有上下布局。

类别列表两端根据剩余滚动距离呈现渐隐羽化；到达边界时对应侧恢复完整显示，无溢出时不显示羽化。调整窗口或双栏宽度时重新测量，不使用遮挡点击的覆盖层。

## 类别接口与模型

`GET /contract/api/contract/categories` 通过统一 `contractApiFetch` 携带 Bearer 凭据，开发模式沿用 `/dev` 前缀与 Nginx 转发链路。响应建模为 `{ categoryId, code, name }`，分别映射 `category_id`、`code`、`name`，按类别 ID 升序排列。ID 必须是安全整数，编码与名称必须是非空字符串；重复 ID、重复编码或无效结构会显示格式错误，不静默过滤。相同名称可以对应不同类别。

工作台挂载时拉取一次，切换合同库与处理流不重复请求。加载、失败可重试和成功空数组分别展示不同状态；空数组不回退到示例类别。组件卸载时取消请求，过期响应不更新当前模型。`401` 由统一鉴权入口处理退出。

## 正式合同目录接口与模型

`GET /contract/api/contract/documents` 使用同一鉴权入口，无参数、无分页，返回所有已登录审核人共享的 ready 合同目录，不包含 ingesting 记录。响应必须为 `200` 数组，空数组表示暂无已入库合同；`401` 沿用统一退出逻辑。

`contractDocuments.js` 将七个接口字段映射为 `id`、`name`、`categoryRaw`、`date`、`fileUri`、`reviewer`、`ingestedAt`。验证文档身份及唯一性、字段类型、可空签订日期、根相对文件地址和带时区入库时间；格式异常作为错误展示，不静默丢弃记录。模型保留服务端的入库时间倒序、文档 ID 升序，界面另按签署日期分组排序。

`categoryRaw` 按 `/` 分割、去除两端空白和重复项，生成 `categoryTokens`。类别模型到达后按 `code` 精确关联，生成筛选用 `categoryCodes` 与展示用类别名称。多类别合同匹配任一所属类别；不做子串或名称猜测。未映射项保留原说明，在全部合同中仍然可见。两个接口独立加载，类别重试成功后自动重新解析目录，不必再次请求合同。

登录后组件首次挂载时拉取类别与目录；等待工作台入场结束、首次请求结束（含失败）和布局提交，再将档案区域整体淡入，不逐个播放初始表项动画。工作台采用持续挂载方式保留组件实例，具备页面切换缓存效果，无须额外套用 KeepAlive；返回合同库不重复请求，筛选及滚动位置保持。点击“刷新”主动获取最新目录，删除成功后也会刷新；处理流新入库的合同可通过手动刷新获取。退出登录会销毁实例与缓存。

手动刷新时，当前可见表项及日期分割线先统一向上淡出，等待请求结束与退场完成后，将最新结果交错淡入一次；数据相同也执行这一次切换。请求期间的数据变化不另外触发动画。失败时重新展示保留的旧目录，并显示重试入口。圆形刷新图标持续旋转，在请求结束后转完当前一圈再停止。减少动态效果时直接更新。首次加载、成功空目录与无匹配结果分开处理，不回退到示例数据。新请求取消旧请求，过期响应不覆盖当前模型，卸载时取消请求。

## 合同 PDF 预览

点击合同条目（或键盘聚焦后按回车）打开现有 `PdfPreviewOverlay` 弹窗。通过 `GET /contract/api/resource/contract` 请求，使用目录中的 `fileUri` 原值经 `URLSearchParams` 编码为 `file_uri`，沿用 Bearer 鉴权；不直接将资源地址或免登码拼入 iframe。

PDF 首次读取仍通过鉴权接口且不使用 HTTP 缓存，验证成功状态与 PDF 媒体类型后，将二进制转换为临时 Blob URL 交给 PDF.js 阅读器。同一登录期间按处理版 PDF 地址在内存中复用成功下载的文件，重复打开不再请求文件接口；最多保留最近使用的 5 份且总计不超过 100 MiB，超过单文件上限时仅用于当前预览，退出登录或组件卸载时清空。关闭仍释放阅读器与临时 URL，不保留页码、缩放等阅读器状态。删除成功或目录刷新发现文件不再存在时移除对应缓存，失败重试跳过缓存重新读取。摘要、注意事项和关联仍按各自读取规则更新。加载中可关闭，失败显示重试；关闭、切换工作台或卸载时取消未完成请求并释放 Blob URL，过期响应不再打开弹窗。文件仅在点击时读取，不预加载目录内所有 PDF。合同库使用前端 PDF.js 阅读器，点击后立即渲染文件名、页码和缩放工具栏，文件加载期间控件禁用、页数显示占位；解析后启用翻页、页码跳转、缩放、适应宽度及下载。页面连续滚动并支持文字选择，按可视区域渲染；PDF 内容区支持触控板及触屏双指缩放，围绕手势位置缩放并同步工具栏百分比，范围为 25%–400%，普通双指滑动仍滚动页面；加减按钮围绕阅读区中心进行约 240ms 缓出缩放，连续点击累积目标比例，手势缩放、翻页、适应宽度或关闭时取消旧过渡，系统减少动态效果时直接缩放；关闭时销毁加载任务、阅读器和 worker。加载或解析失败保留工具栏和重试入口。其他预览入口仍使用浏览器内置阅读器。

当前不实现独立下载入口、编辑、服务端筛选或分页。

正式合同预览右侧居中提供圆形工具栏，所有已登录用户均可见并支持悬停效果，均可使用删除按钮及确认卡片。查重候选预览不显示工具栏，当前合同可通过 pin 按钮加入会话引用。

## 合同摘要气泡

正式合同预览左上方、PDF 工具栏下方提供圆形问号按钮，悬停、键盘聚焦或点击时显示摘要气泡；鼠标可移入气泡阅读与滚动，移出后收起，Escape 仅关闭当前气泡。按钮与气泡使用蓝灰色磨砂样式，长内容在气泡内滚动。进入注意事项层时摘要气泡关闭，附件与处理流预览不显示摘要入口。

摘要气泡请求期间显示居中的圆环 loading；加载完成后圆环淡出，摘要正文或空状态在约 550ms 内轻微上移并淡入，遵循系统减少动态效果设置，不额外延迟接口请求。

首次展开气泡时通过 `GET /contract/api/contract/documents/{document_id}/summary` 读取，沿用统一 Bearer 鉴权和开发环境 `/dev` 前缀；不发送请求体或查询参数。所有已登录用户可读取共享合同摘要，不按审核人过滤。同一气泡实例读取成功后复用结果，重新打开预览时重新读取；关闭预览或切换合同取消未完成请求，过期响应不覆盖当前合同。

严格校验 200 响应的 `document_id` 与当前合同一致，`summary` 仅接受字符串或 null。文字原样以纯文本展示，不拼接注意事项；null 显示“暂无摘要”，不当作 404。加载过程显示状态，失败显示错误并允许手动重试，401 沿用全局退出逻辑，404、409、422 区分合同不存在、未入库与标识错误。查询不会生成摘要、调用模型或更新会话。后端摘要生成尚未接入时，所有合同均可能暂无摘要。

适配器验证：`node --test tests/contractSummaryApi.test.js`，覆盖 null、文字原样返回、身份校验、请求契约及失败边界。

## 合同注意事项

正式合同预览默认收起注意事项；点击扇形菜单中的“注意事项”按钮后，在当前 PDF 上覆盖模糊遮罩，并居中展示注意事项列表框；PDF 保持原尺寸和位置，按条显示正文、作者和浏览器本地时间，顺序为创建时间升序、同一时间按 `note_id` 排序。文字以纯文本呈现并保留换行，正文最多展示三行，作者与时间单行省略。实际发生溢出时，悬停或键盘聚焦显示完整内容气泡；短文字不显示气泡。气泡优先显示在文字左侧，左侧空间不足时改为右侧，两侧均不足时放在上方或下方，并限制在视口内。气泡支持长内容滚动，列表滚动或窗口变化时关闭，避免错位。作者与时间使用更清晰的深色文字，在表项正文下方靠左分两行标注“审核人：”“审核时间：”。展示值仍分别来自 `author_name` 和 `created_at`，不增加独立审核状态或审核时间字段。注意事项是人工补充意见，不属于合同原文或已核实事实。窄屏仍居中展示，列表框限制在预览可用区域内，列表区域独立滚动，标题与下方新增输入区、操作按钮保持固定。附件与处理流预览不显示该浮窗。

右侧合同操作工具栏通过悬停、键盘聚焦或点击向左呈扇形展开；注意事项、合同关联、删除合同三个操作沿主按钮左侧扇形排列。菜单中的“注意事项”使用上传的图标，可点击展开或收起浮窗。列表框内右上角“＋”用于新增，“×”、点击列表框外的模糊遮罩或 Escape 用于关闭注意事项层并返回 PDF；编辑时 Escape 先取消编辑。注意事项层打开期间底层 PDF 和工具栏不可交互，键盘焦点限制在列表框内。新增对所有登录用户开放，不按作者限制。点击“＋”后新增区域平滑展开，取消或添加成功后平滑收起，列表框随内容高度伸缩；减少动态效果模式下直接切换。收起区域不接收键盘焦点，展开时聚焦输入框，不带动列表滚动。在该区域编辑，支持取消、空白校验及字数提示；正文去除首尾空白后为 1–10000 个 Unicode 码点。首次点击“添加注意事项”仅将按钮切为橙黄色，“确认提交”从下方淡入上移，按钮尺寸、取消按钮与其他布局不变；再次点击才提交。3 秒内未确认自动恢复原按钮，修改正文也会退出确认状态。提交期间按钮显示圆圈 loading，禁止重复提交和关闭注意事项层，失败保留输入且不自动重试，成功后追加记录。loading 由真实请求生命周期驱动，不添加人为延迟。每条注意事项的审核信息右侧提供垃圾桶按钮，与审核人、审核时间并排并底部对齐；点击打开居中的删除确认框，仅展示删除提示、取消及确认删除按钮，不展示注意事项正文，支持 Escape 取消与焦点返回。单条删除通过 `DELETE /contract/api/contract/documents/{document_id}/notes/{note_id}` 提交，无请求体；所有已登录用户均可删除任意作者的注意事项。收到 204 才移除对应项；提交时显示 loading 并禁止重复提交和关闭，失败保留记录与确认框。404（包括重复删除）不视为成功，提示刷新核对；403、409、422、503 分别提示请求被拒绝、状态、标识或服务不可用，401 沿用统一登录失效处理。网络异常不自动重试，也不影响合同及其他注意事项。没有单条编辑入口。收起浮窗会清除未提交草稿，已添加条目由服务端持久化；再次打开 PDF 时浮窗默认收起。

使用 `contractNotesApi.js` 通过统一 `contractApiFetch` 访问真实接口，沿用开发环境 `/dev` 前缀和 Bearer 鉴权。每次打开注意事项层读取最新列表，关闭时取消未完成的 GET 请求；过期响应不覆盖新合同。加载中或读取失败时暂停新增，避免读取结果覆盖并发提交。空数组展示空状态，失败明确提示并支持手动重新加载，不回退到示例数据。

提交仅发送去除首尾空白后的正文，作者、记录 ID 和时间使用服务端响应。网络中断、非预期成功状态或响应格式错误不宣称新增成功，保留草稿并提示先重新打开列表核对，避免重复提交。POST 不自动重试、不主动中止。读取与提交均校验返回记录格式。

接口契约：

- `GET /contract/api/contract/documents/{document_id}/notes`：Bearer 鉴权，无请求体或分页参数，200 返回数组，无注意事项时返回 `[]`。
- `POST` 同一路径：JSON 只提交 `{ content }`；201 返回 `note_id`、`content`、`author_name`、`created_at`。真实作者、UTC 时间和 ID 必须使用服务端返回值，不由客户端指定。
- 路径 ID 为处理版 PDF 的 64 位小写 SHA-256；401 沿用统一认证处理，404 表示合同不存在，409 表示尚未入库，422 表示参数不合法，错误体使用 FastAPI `detail`。
- POST 不幂等，相同内容重复提交产生独立记录；不自动重试、不做内容去重。注意事项接口不更新模型会话、ES 或任务快照，合同删除时由服务端级联清理。

适配器回归：`node --test tests/contractNotesApi.test.js`，覆盖请求路径、仅 content 的 JSON 正文、登录认证、响应模型、错误状态、401 会话失效及 POST 不自动重试。真实新增会产生持久记录，联调应选定测试合同与明确测试内容。

## 删除正式合同

所有已登录用户可以删除任意审核人入库的正式合同，不按审核人归属限制。二次确认明确提示无自动备份、无法撤销，通过 `DELETE /contract/api/contract/documents/{document_id}` 发送 Bearer 请求，参数只允许 64 位小写十六进制 ID，无查询参数和请求体。仅 `204` 作为成功，不解析空响应体；成功后关闭预览、释放 PDF 资源、从本地目录移除记录并刷新服务端目录，刷新失败仍保持已删除记录移除。失效年份筛选同步重置。

提交期间禁止重复删除、取消确认和关闭弹窗，不主动中止删除请求。失败保留同一文档 ID：`403` 提示服务端拒绝请求，`404` 提示目录已不存在，`409` 提示尚未完成入库，`422` 提示 ID 错误，`502` 明确告知可能部分完成、需重试同一合同；网络中断也不宣称删除成功。`401` 沿用统一退出逻辑。PDF 读取失败时仍允许打开工具栏，以便重试清理残留摘要；不自动重试或进行客户端回滚。

后端清理正式 ES 文档、PDF、SQLite 摘要及关联，不删除类别字典、历史备份、实验产物或内存提取任务。前端不额外操作这些资源。模拟接口回归：`node --test tests/contractDeletion.test.js`，不删除真实数据。

## 验证要点

检查类型与年月日组合筛选、跨年筛选、月日留空、月末及闰年修正、空结果、结果数量和分组顺序；检查双栏拖拽、窄屏布局、滚轮键盘上下键与首尾键操作和工作台切换后筛选状态保留。运行项目构建检查组件与样式编译。日期规则测试：`node --test tests/contractDateFilter.test.js`。

类别模型回归测试：`node --test tests/contractCategories.test.js`，覆盖映射排序、空数组、无效字段与身份重复。接口联调应检查实际鉴权链路及真实类别渲染。

目录模型回归测试：`node --test tests/contractDocuments.test.js`，覆盖字段映射、顺序保留、空数组、非法字段、多类别精确匹配、未映射类别、真实审核人及日期组合筛选。联调还应检查返回合同库不重复请求、手动刷新相同数据无动画、变化数据仅切换一次、加载失败保留旧记录与重试。

合同类别按完整合同目录中各类别的合同数降序排列，“全部合同”固定在首位；数量相同时按类别 ID 升序，零合同类别保留在后。多类别合同分别计入每个所属类别，排序不随日期或审核人筛选变化，刷新目录或删除合同后重新计算。

摘要按钮下方的 pin 按钮使用 `src/assets/pin.webp` 图标，选中时反白；可将当前合同加入会话引用，再次点击取消；选中状态跟随当前会话草稿。所有已登录用户均可使用，无需等待 PDF 下载完成。引用以附件标签样式显示于输入区，可移除，具体请求与历史行为见[智能助手会话交互](agent-conversation.md#正式合同引用)。

## 合同关联浮层

正式合同预览的多功能菜单新增关联入口，使用 `link.webp`（由提供的 PNG 无损转换）。注意事项、关联、删除沿左侧扇形分布。关联与注意事项复用 PDF 模糊遮罩和居中卡片，一次只展示一种面板；Escape、关闭按钮或点击遮罩返回 PDF，键盘焦点限制在当前浮层内。

列表每项展示关联文件名称、描述、创建人、创建时间及垃圾桶按钮；创建信息直接使用服务端 `created_by` 和 `created_at`，时间转换为浏览器本地时间，在描述下方靠左分两行对齐，垃圾桶与其并排底部对齐。姓名与时间超长时省略，并可通过气泡查看全文；名称单行、描述三行截断，溢出时沿用完整内容气泡。右上角仅保留与注意事项同款的新增、关闭按钮，不提供刷新按钮；加号伸展新增表单，列表独立滚动。文件选择在输入非空关键字后展开搜索框下方的浮动下拉列表，在已加载的完整合同目录中按名称关键字筛选；支持上下键选择、Enter 确认、Escape 收起，选中后回填名称并关闭下拉，修改关键词清除旧选择，失焦或表单滚动时收起；不受目录当前筛选条件影响，不额外查询后端。当前 UI 排除自身与已选关联对象，要求选中文件并填写非空描述；删除须确认，仅移除关联项。

关联已接入真实接口，所有登录用户均可操作，无修改描述入口。每次打开浮层通过 `GET /contract/api/contract/documents/{document_id}/relations` 获取最新一跳列表，按创建时间降序、同时间按关系 ID 升序展示；列表中的 `document_id` 是对方合同。关联对象不在前端目录中时补拉一次完整目录，仍缺少时提示重试，不以占位文件名代替。加载失败显示错误并允许刷新，不回退到内存演示数据；关闭时取消 GET，过期响应不更新界面。

新增通过 `POST /contract/api/contract/relations`，仅提交 `document_id_a`、`document_id_b` 和去除首尾空白的 `description`，校验不同的完整合同 ID 与 1–10000 个 Unicode 码点。201 响应中的 ID、创建人、时间和描述为最终记录；端点按字典序返回，不能依赖请求顺序识别对方。两份合同之间只能有一条无向关联。成功后收起表单并更新列表，失败保留草稿；409 提示已有关系或合同状态/图节点待同步，通过刷新列表核对，不覆盖已有描述。

删除确认后通过 `DELETE /contract/api/contract/relations/{relation_id}` 发送无请求体请求，收到 204 后移除列表项；404 提示关联已不存在，保留确认框，取消并重新打开浮层后可核对最新列表。删除只影响关联，不影响合同。提交与删除期间显示圆环 loading，禁用重复提交及浮层关闭；写请求不主动中止、不自动重试。网络中断或响应格式异常不宣称成功，提示刷新核对实际结果。401 沿用登录失效处理，404、409、422、502 分别提示不存在、冲突、参数错误或服务不可用。返回关系网页面时重新查询已有中心的一跳数据，避免展示修改前的关系。

适配器回归：`node --test tests/contractRelationsApi.test.js tests/contractNetworkApi.test.js`，覆盖精确请求体、Bearer 鉴权、无向端点顺序、描述边界、204 空响应、重复删除、错误状态及写请求不自动重试。
