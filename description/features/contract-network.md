# 合同关系网

关系网页面位于 `/network`，用于从一份合同出发浏览直接关联。页面使用正式合同目录及一跳关系查询接口；合同预览中新增或删除关联后，返回关系网页面会重新读取当前中心的一跳数据。

## 展示与交互

页面采用左右两栏：左侧上部提供合同名称搜索，标题随选择状态显示“选择一份中心合同”或“当前中心合同”；上部按内容高度布局，仅为返回按钮与关联合同计数预留一行。下拉选择或键盘确认后展开一层关系；输入框同步显示当前中心合同，点击节点切换中心后同步更新，点击 × 清除选择并回到待机。可返回上一个中心。左侧下部保留点击选中的详情：合同展示目录中的名称、摘要、类别、审核人、签署日期和入库时间；关联展示两端合同、用户填写的关系说明、创建人和创建时间。时间以北京时间显示，空签署日期显示占位。详情为空时淡入并保留 `sleep.webp` 图片；空状态与详情之间、不同合同或关联详情之间均先淡出再淡入，标题和正文一起切换，同一对象内容更新时也执行过渡，进入新内容时重置详情滚动位置。减少动态效果时直接切换。鼠标移开不会清空详情，点击当前中心可以从关联详情切回合同信息；切换中心或清除选择会更新详情。右侧展示三维关系网。窄屏时选择与详情位于图的上方。

分栏沿用合同库的玻璃切面与中部渐变握柄，支持拖动以及左右方向键、Home、End 调整。左栏默认及最小宽度为 360px，右侧关系网至少保留 640px；父容器变化时重新约束宽度，右侧画布随布局实时调整。容器不足 1000px 时转为上下布局并隐藏握柄。所调宽度在页面切换期间保留，刷新或退出登录后恢复默认；拖拽在指针取消、丢失捕获、页面切换和卸载时结束。

节点参考大背景分子：小圆点、纤细连线和灰绿、青蓝、淡紫色调，不使用卡片、实体原子或星球轨道。按合同 ID 稳定生成不同分支数量、方向和配色，分子与关联虚线使用较深的颜色以保证识别；中心节点适度放大，采用更饱和的同色高亮和核心柔光，名称在下方朝向镜头显示。切换中心时，高亮随节点缩放平滑交接。拖动旋转、滚动缩放，点击外围节点切换中心；可重置视角。悬停被截断的名称显示完整文本。合同之间使用虚线，按关联 ID 稳定生成不同大小和方向的弧度，并保留部分直线；切换中心不会重新随机。虚线本身沿路径缓慢流动，不叠加光点，流动不表示业务方向；分子内部保持细实线。悬停关系连线高亮，点击后在左侧显示关联详情并保持该连线高亮。无关联时保留中心合同。

点击关联节点后，前端保留该节点及共同节点当前的世界坐标、移动速度，使用欠阻尼弹簧加速移向新的目标位置，经过轻微过冲后收稳；不会先把点击节点重置到原点。新引入的节点稍晚淡入，退出的节点和关系先淡出再移除。快速连续切换从当前帧继续运动，镜头保留用户旋转后的方向。减少动态效果模式直接收敛到最终状态，虚线静止。

未选择合同时展示缓慢自动旋转的无名称线点分子群，关闭拖动、滚轮、触控等视角操作；悬停分子可以高亮，点击节点或连线均无操作。选择合同后恢复视角控制。页面不出现 mock、演示提示、重复标题及宣传文案，仅保留搜索、关联数量、必要控制及状态提示。

使用 `3d-force-graph` 与 Three.js 绘制真实 WebGL 三维场景。前端负责稳定的三维坐标和过渡动画；分子自身的小分支只区分节点外观，不代表额外合同。进入关系网页面才加载引擎。隐藏页面或浏览器标签时暂停渲染及运动时间，退出时释放图实例、几何体、材质和纹理。浏览器需要支持 WebGL。

## 数据边界

首次进入关系网，通过正式合同目录与类别接口构建搜索列表，页面持续挂载时复用；支持手动刷新合同列表。加载、失败、空目录和无匹配结果分别展示，不回退到示例数据。目录刷新禁用 HTTP 缓存。

`services/contractNetworkApi.js` 使用统一 Bearer 鉴权调用 `GET /contract/api/contract/documents/{document_id}/relations`，ID 必须为完整的 64 位小写 SHA-256。无请求体、深度或分页参数，仅接受 200 数组；空数组表示有效合同没有可见关联。校验关系 UUID、对方合同 ID、描述、创建人和带时区时间，保留服务端顺序及描述原文。关系查询不访问 PDF、摘要、ES 或模型；不递归获取邻居的关系。合同详情另通过 `GET /contract/api/contract/documents/{document_id}/summary` 按需读取当前合同摘要，显示圆环加载并淡入正文；null 显示“暂无摘要”，失败提供重试。摘要原样以纯文本呈现并随详情区域滚动；切换合同、选择关联、离开页面或卸载会取消原请求，过期结果不覆盖新合同。

收到关系后，按中心 ID 和所有对方 ID 查找前端合同模型；任一缺失时先重新拉取一次完整合同目录及类别，再构建关系图。刷新后仍缺失时提示合同可能被删除或状态改变，停止本次展示，不以占位名称或缺边图冒充成功，也不无限重试。目录及图结果只在当前查询成功且未过期时一起提交；失败保留原视图并提示重试。

关系为无向关系，内部固定两端 ID 的顺序以保持反向探索时的视觉连续性，不改写描述。`models/contractNetwork.js` 按合同 ID 和关联 ID 分别去重，排除自关联和非中心关联；同一对合同的不同关联 ID 保留。接口不提供关系类型，前端不从描述中推测类型。

401 触发统一登录失效处理；404 提示合同不存在或已删除；409 提示入库、删除或图节点同步状态；422 提示标识无效；502 提示关联服务不可用。错误或非法响应不解释为无关联。快速切换与清除选择会取消当前查询及其补拉目录请求，旧响应不覆盖新选择；卸载时取消请求。查询结果仅为当次可见状态，后续可能因并发操作变化。场景由 `services/contractNetworkScene.js` 管理，页面负责搜索和导航状态。

## 验证

`node --test tests/contractNetworkApi.test.js tests/contractNetwork.test.js tests/networkMotion.test.js` 验证请求契约、缺失模型时仅刷新一次目录、刷新后仍缺失、无向映射、响应校验、认证及错误状态、取消请求、去重、自关联排除，以及运动连续性与淡入边界。结合浏览器验证两栏布局、搜索与中心名称同步、节点及关联详情、清除与返回、待机自动旋转及视角锁定、已选合同的旋转及缩放；构建使用 `npm run build`。
